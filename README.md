# 🚀 OpenWrt Smart Sidecar Gateway

Универсальный интерактивный установщик для превращения любого устройства на **OpenWrt** (x86_64, миникомпьютеры Z83, Raspberry Pi и др.) в прозрачный умный шлюз, домашний микро-сервер и сетевое хранилище (NAS).

---

## ⚡ Быстрый старт (Установка в одну команду)

Подключитесь к роутеру по SSH и вставьте команду:

```bash
curl -sL https://raw.githubusercontent.com/unknownpeace/OpenWrt-gateway/main/install.sh -o install.sh && chmod +x install.sh && ./install.sh
```

---

## 🌟 Что умеет этот скрипт

Скрипт автоматически опрашивает параметры, настраивает стек ядра Linux и разворачивает полноценный комплекс сервисов:

### 1. 🛡 Прозрачный шлюз в одной подсети (Sidecar Gateway)
* Работает параллельно с вашим основным роутером (например, Keenetic, MikroTik, ASUS).
* Не требует разделения сети на WAN/LAN — работает через один сетевой порт.
* **Masquerade на LAN:** исключает асимметричную маршрутизацию и разрывы TCP-сессий.
* **Защита от ICMP Redirects:** предотвращает уход клиентов в обход туннеля.
* **MSS Clamping (`mtu_fix='1'`):** гарантирует мгновенное открытие тяжелых HTTPS-сайтов с большими сертификатами без подвисаний.

### 2. ⚡ Mihomo (Clash.Meta) TUN + Sniffer
* Автоматически скачивает **актуальную последнюю версию ядра Mihomo** с GitHub.
* Работает через интерфейс ядра **`tun0`** с автоматической маршрутизацией (`auto-route: true`).
* **Умная маршрутизация:** сайты РФ и локальные сети идут напрямую на максимальной скорости провайдера (`DIRECT`), заблокированные ресурсы — через прокси-туннель.
* **Sniffer (TLS/HTTP/QUIC):** перехватывает SNI доменов из сетевых пакетов для безошибочного распределения трафика.
* Встроенная веб-панель **MetaCubeXD** для управления нодами и правилами.

### 3. 🎯 AdGuard Home (DoH + Adblock)
* Работает на стандартном порту **53** для всей локальной сети.
* В качестве апстрима использует **Mihomo Fake-IP (1053)** — блокирует рекламу и трекеры на всех устройствах (ТВ, телефоны, ПК) до отправки запроса в туннель.
* Автоматически хэширует ваш пароль в **bcrypt** (`$2y$10$...`) при установке.

### 4. 📁 KSMBD (Сверхбыстрый NAS / Samba)
* Работает на уровне ядра Linux — потребляет в 10 раз меньше оперативной памяти, чем классическая Samba 4, выдавая максимальную скорость USB/диска.
* Создает общую сетевую папку `/mnt/share` с полными правами **`0777`** на все новые файлы.
* **Гостевой доступ наглухо закрыт (`guest_ok 'no'`):** вход строго по вашему логину и паролю.

### 5. 📥 Aria2 + Веб-интерфейс AriaNg (Опционально)
* Автономная фоновая качалка файлов и торрентов.
* Качает файлы напрямую в сетевую папку `/mnt/share`.
* Защищена вашим единым паролем (RPC Token).

### 6. 📦 Контейнеры LXC (Опционально)
* Готовая среда для запуска легковесных контейнеров (Alpine, Debian, Kali и др.).
* Автоматически патчит конфиг (`lxc.net.0.link = br-lan`), привязывая новые контейнеры напрямую к домашней сети.

## 🔑 Единая учётная запись (Master Credentials)

Вам больше не нужно настраивать каждую службу отдельно. В начале установки скрипт запрашивает **один логин и один пароль**, которые автоматически прописываются в:
* **AdGuard Home** (с генерацией bcrypt-хэша)
* **KSMBD** (авторизация сетевой папки)
* **MetaCubeXD** (секретный ключ доступа к панели)
* **Aria2 RPC** (токен авторизации веб-морды)
* **OpenWrt root** (опционально по желанию)

## 📱 Настройка устройств (ПК, Телевизор, Телефон)

Чтобы устройство пошло через шлюз, в свойствах сети (Wi-Fi или Ethernet) укажите:
* **IP-адрес:** любой свободный (например, `192.168.1.50`)
* **Маска подсети:** `255.255.255.0`
* **Основной шлюз (Gateway):** IP вашего OpenWrt (например, `192.168.1.1`)
* **DNS-сервер:** IP вашего OpenWrt (например, `192.168.1.1`)

## 🌐 Панели управления

| Сервис | Адрес | Авторизация |
| :--- | :--- | :--- |
| **LuCI (OpenWrt)** | `http://<IP_OPENWRT>` | `root` / Ваш пароль |
| **AdGuard Home** | `http://<IP_OPENWRT>:3000` | Ваш логин / Ваш пароль |
| **MetaCubeXD (Mihomo)** | `http://<IP_OPENWRT>:9090/ui` | Секрет: Ваш пароль |
| **AriaNg (Торренты)** | `http://<IP_OPENWRT>/ariang` | Токен: Ваш пароль |
| **Сетевая папка** | `\\<IP_OPENWRT>\Share` | Ваш логин / Ваш пароль |
| **SSH / SFTP** | Порт `22` | `root` / Ваш пароль |

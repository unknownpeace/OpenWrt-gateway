# OpenWrt Transparent Gateway (Mihomo TUN + AdGuard Home)

Легковесный, полностью автономный скрипт для превращения любого x86_64 мини-ПК (включая энергоэффективные устройства на Intel Atom Z8350 / N3350 / N100) в домашний прозрачный сетевой шлюз на базе **OpenWrt**.

Стек ориентирован на максимальное быстродействие, минимальное потребление оперативной памяти (~120 МБ в работе) и полное отсутствие необходимости ставить клиенты VPN на конечные устройства (телевизоры, телефоны, приставки, ПК).
```
(which curl >/dev/null && curl -sL https://raw.githubusercontent.com/unknownpeace/OpenWrt-gateway/main/install.sh -o install.sh || wget -qO install.sh https://raw.githubusercontent.com/unknownpeace/OpenWrt-gateway/main/install.sh) && sh install.sh
```

## 🚀 Основные возможности

* **Маршрутизация на уровне ядра (TUN-режим):** Ядро Mihomo перехватывает весь исходящий трафик через интерфейс `tun0`.
* **Умное разделение трафика (Smart Routing):**
  * Ресурсы РФ (`.ru`, `.su`, `category-ru`, `GEOIP RU`), локальные сети и банки идут **напрямую (DIRECT)** на полной скорости провайдера.
  * Заблокированные и зарубежные сервисы автоматически направляются через **прокси-туннель**.
* **Двойная защита DNS (AdGuard Home + Fake-IP):**
  * Клиенты сети обращаются на порт `53` (**AdGuard Home**) — блокируются трекеры, реклама и фишинг.
  * Очищенные запросы передаются на локальный порт `1053` (**Mihomo Fake-IP DNS**), что исключает утечки DNS (DNS Leaks) и ускоряет отклик.
* **Автовыбор узлов и автообновление:**
  * **Автообновление подписки:** раз в 24 часа в фоновом режиме без разрыва соединений.
  * **Группа `AUTO` (url-test):** каждые 5 минут тестирует все узлы и переключает трафик на сервер с минимальной задержкой (пингом).
  * **Ручное управление:** в веб-панели можно в один клик принудительно выбрать любую страну/сервер.
* **Режим без паролей (Zero-Auth):** Доступ к веб-панелям AdGuard Home и MetaCubeXD открывается сразу без запросов паролей и токенов.
* **Работа в одной подсети (Single-NIC Gateway):** Требуется только один физический Ethernet-порт на мини-ПК. Шлюз работает параллельно с основным роутером.

```text
[ Устройства в сети (ПК, ТВ, Смартфоны) ]
                     │
                     ▼ (Шлюз & DNS: IP OpenWrt)
           ┌─────────────────────┐
           │   OpenWrt Gateway   │
           └──────────┬──────────┘
                      │
        ┌─────────────┴─────────────┐
        │                           │
  [ DNS-запрос :53 ]          [ TCP/UDP Трафик ]
        │                           │
        ▼                           ▼
 ┌───────────────┐           ┌───────────────┐
 │ AdGuard Home  │           │   nftables    │
 │ (Фильтрация)  │           │  Masquerade   │

        │                           │
        ▼                           │
 ┌───────────────┐                  │
 │  Mihomo DNS   │                  ▼
 │  (:1053 Fake) │           ┌───────────────┐

            [ РФ / Локальный ]             [ Зарубежный / Блок ]
